# Setup AI Installer

## What is Setup AI Installer?

Setup AI Installer helps you find and install MCP servers and skills worth using in real projects. A curated selection for Claude Code, Codex, Antigravity, and OpenCode, chosen for practical value beyond the hype.

The collection ranges from token savers and UI tools to language-specific skills and reverse engineering. The goal is simple: less time sorting through recommendations, more time using tools that help.

## How to use it

Run this in your command shell:

```sh
npx setup-ai-installer@latest
```

Everything after that should be self-explanatory.
